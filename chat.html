" မင်္ဂလာပါ " ***** ဝင်ရောက်ကြည့်ရှုပေးလို့ ကျေးဇူးအများကြီး တင်ပါတယ် *****

ဆွေးနွေးပွဲ စကားဝိုင်း

အကောင့်အသစ် ဖွင့်နည်းနှင့် Login ဝင်နည်း လမ်းညွှန်ဖြစ်ပါတယ်။

အကောင့်အသစ် ဖွင့်ရန် (Sign Up / Register)
  • Email နေရာတွင်: မိမိဖုန်း/ကွန်ပျူတာထဲတွင် အသုံးပြုနေသော Gmail လိပ်စာ (ဥပမာ- yourname@gmail.com) ကို ရိုက်ထည့်ပါ။
  • Password နေရာတွင်: မိမိ မှတ်မိလွယ်မည့် စကားဝှက်ကို အနည်းဆုံး ၆ လုံး (ဥပမာ- 123456 သို့မဟုတ် myPass1) ထည့်သွင်းပါ။
  • အကောင့်ဖွင့်ရန်: Email နှင့် Password ဖြည့်ပြီးပါက "Signup (အကောင့်အသစ်ဖွင့်မည်)" ဆိုသည့် ခလုတ်ကို နှိပ်ပါ။
  • အကောင့်ဖွင့်ခြင်း အောင်မြင်သွားပါက စကားစတင် ပြောဆိုနိုင်ပါပြီ။
အကောင့်သို့ Login ဝင်ရန် (Sign In / Login)
  • Email နေရာတွင်: အကောင့်ဖွင့်စဉ်က အသုံးပြုခဲ့သော ဖုန်းနံပါတ် (သို့မဟုတ်) အီးမေးလ်ကို ရိုက်ထည့်ပါ။
  • Password နေရာတွင်: အကောင့်ဖွင့်စဉ်က အသုံးပြုခဲ့သောစကားဝှက်ကို ရိုက်ထည့်ပါ။
  • "Login ( ဝင်မည် )" ဆိုသည့် ခလုတ်ကို နှိပ်၍ အကောင့်ထဲသို့ စတင်ဝင်ရောက် အသုံးပြုနိုင်ပါပြီ။
Password (စကားဝှက်) မမှတ်မိပါက ပြန်လည်ယူနည်း
  • Email ထည့်ပါ: Email နေရာတွင် အကောင့်ဖွင့်ခဲ့စဉ်က အသုံးပြုခဲ့သော မိမိ၏ Email ကို ရိုက်ထည့်ပါ။
  • "Password မေ့နေပါသလား?" ကိုနှိပ်ပါ: ထို့နောက် အောက်ပါ "Password မေ့နေပါသလား?" ဆိုသည့် စာသားလေးကို နှိပ်ပါ။
  • Mail စစ်ဆေးပါ: သင့် ဖုန်း သို့မဟုတ် ကွန်ပျူတာ၏ Gmail Inbox ထဲသို့ Password ပြောင်းလဲရန် Link တစ်ခု ရောက်ရှိလာပါမည်။
  • Spam Folder စစ်ရန်: Gmail ၏ Inbox (ပင်မစာမျက်နှာ) တွင် စာကို တိုက်ရိုက်မတွေ့ရပါက Spam (အမှိုက်ပုံး) Folder ထဲသို့ ဝင်ရောက် စစ်ဆေးပေးပါ။
  • Password အသစ် ပြောင်းရန်: ရောက်ရှိလာသော Link ကိုနှိပ်၍ Password အသစ်ရိုက်ထည့်ပြီး အတည်ပြုပေးလိုက်ပါက အကောင့်သို့ ပြန်လည် ဝင်ရောက် အသုံးပြုနိုင်ပါပြီ။
